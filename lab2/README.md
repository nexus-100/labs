# Лабораторная работа № 2 — регулярные выражения и unit-тестирование

**Тема:** проверка и поиск географических координат (широта и долгота).

## О работе

Программа на Python проверяет, соответствует ли строка формату географических координат, и находит такие координаты в произвольном тексте, локальном файле или тексте загруженной веб-страницы. В качестве предметной области используются координаты станций проката велосипедов, связанных с лабораторной работой № 1.

Для проверки и поиска применяется регулярное выражение. Корректность функций подтверждается автоматическими unit-тестами на базе `unittest`.

## Возможности

- проверка одной пары координат целиком;
- поиск координат в произвольном тексте;
- поиск в локальном UTF-8-файле;
- загрузка веб-страницы по HTTP/HTTPS и поиск координат в её тексте;
- поддержка десятичных градусов со знаком и записи с обозначением полушария;
- поддержка латинских обозначений `N/S/E/W` и русских `С/Ю/В/З`;
- проверка допустимых диапазонов широты и долготы;
- обработка ошибок чтения файлов и сетевых запросов;
- автоматические тесты с имитацией сетевых ответов.

Проверяется синтаксическая корректность записи координат. Программа не определяет географическое положение объектов по внешним картографическим данным.

## Требования

- Python 3.10 или новее;
- пакет `requests` для загрузки веб-страниц.

Установите зависимости из каталога `lab2`:

```bash
python -m pip install -r requirements.txt
```

## Запуск программы

Перейдите в каталог лабораторной работы:

```bash
cd lab2
```

Запустите интерактивное приложение:

```bash
python app.py
```

В меню доступны проверка введённой координаты, поиск в тексте, поиск в файле и поиск на веб-странице.

## Запуск тестов

Из каталога `lab2` выполните:

```bash
python -m unittest discover -v
```

Тесты проверяют корректные и некорректные координаты, разбор и поиск совпадений, чтение файлов, обработку HTML, сетевые ошибки и работу меню. Сетевые запросы в тестах имитируются, поэтому для выполнения unit-тестов реальное подключение к интернету не требуется.

## Регулярное выражение

Регулярное выражение поддерживает два варианта записи пары координат:

- со знаком: `55.7558, 37.6176`, `-33.8688; 151.2093`;
- с обозначением полушария: `55.7558° N, 37.6176° E`, `33.8688° Ю, 70.6693° З`.

Широта ограничена диапазоном от 0 до 90 градусов, долгота — от 0 до 180 градусов. Для каждого значения обязательна дробная часть от одной до восьми цифр. При записи с обозначением полушария направление определяется буквами: `S/Ю` и `W/З` задают отрицательное значение.

При поиске используются ограничения на соседние символы, чтобы не выделять координату как часть более длинной последовательности.
