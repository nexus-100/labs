## Тема

Проверка и поиск географических координат (широта, долгота) в десятичных
градусах. Предметная область связана с ЛР1: координаты станций проката
велосипедов.

Поддерживаемые форматы:

| Формат | Пример |
|--------|--------|
| Десятичные градусы со знаком | `55.7558, 37.6176`, `-33.8688; 151.2093` |
| Десятичные градусы с полушарием | `55.7558° N, 37.6176° E`, `33.8688° Ю, 70.6693° З` |

Правила: широта 0–90, долгота 0–180 (знак или буква полушария задаёт
направление), обязательная дробная часть из 1–8 цифр, без ведущих нулей.

## Структура

```
lab2/
├── coordinates.py   # регулярное выражение, Coordinate, проверка и поиск
├── sources.py       # чтение файла и загрузка страницы по URL (requests)
├── app.py           # консольное меню
├── data/            # примеры: stations.txt, stations.html
├── tests/           # unit-тесты (unittest)
├── docs/            # отчёт
└── requirements.txt
```

## Запуск

```
pip install -r requirements.txt
python app.py
python -m unittest discover -v
```

Покрытие (при установленном `coverage`):

```
coverage run -m unittest discover
coverage report -m
```
