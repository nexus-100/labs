# Лабораторная работа № 1 — система проката велосипедов

## О работе

Учебный проект на Python, моделирующий предметную область проката велосипедов с использованием объектно-ориентированного программирования. Программа предназначена для демонстрации классов и связей между сущностями, базовых операций управления данными, обработки исключительных ситуаций и сериализации.

## Основные возможности

- представление сущностей предметной области проката велосипедов с помощью классов;
- операции добавления, поиска, изменения и удаления записей о велосипедах и арендах (CRUD);
- проверка входных данных и обработка ошибок с помощью собственных исключений;
- сохранение и загрузка данных в форматах JSON и XML;
- демонстрационный набор данных;
- консольный интерфейс для взаимодействия с системой;
- демонстрационный сценарий работы программы, включая проверку ошибочных ситуаций;
- UML-диаграммы классов в составе отчёта.

## Требования

- Python 3.10 или новее;
- внешние библиотеки для базового запуска не требуются.

## Запуск

Перейдите в каталог `lab1` и выполните:

```bash
python main.py
```

Для запуска демонстрационного сценария:

```bash
python demo.py
```

## Форматы данных

Программа поддерживает сохранение и загрузку данных в форматах JSON и XML. Это позволяет представить данные одной предметной области в двух форматах и продемонстрировать сериализацию и десериализацию.
