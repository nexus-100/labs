# Учебные лабораторные работы по Python

Репозиторий объединяет учебные работы по программированию на Python в рамках дисциплины «Прикладное программирование».

## Содержание репозитория

| Работа | Тема | Что реализовано | Документация |
|---|---|---|---|
| ЛР1 | ООП: модель проката велосипедов | Модель предметной области, операции добавления, поиска, изменения и удаления, обработка ошибок, сохранение и загрузка JSON/XML, UML-диаграммы | [README лабораторной](lab1/README.md), [Отчёт](<lab1/отчет прикладное программирование 1 лаба.pdf>) |
| ЛР2 | Регулярные выражения и unit-тестирование | Проверка и поиск географических координат в тексте, файлах и веб-страницах; обработка ошибок; автоматические тесты | [README лабораторной](lab2/README.md), [Отчёт](<lab2/docs/отчет прикладное программирование 2 лаба.docx>) |

## Как начать работу

1. Выберите лабораторную работу в таблице выше.
2. Откройте README соответствующей работы и ознакомьтесь с описанием проекта.
3. Проверьте требования к версии Python и зависимостям.
4. Следуйте инструкциям по запуску программы и тестов.
5. Отчёты и дополнительные материалы находятся в папке `docs/` соответствующей лабораторной работы.
